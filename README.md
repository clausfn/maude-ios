# liviqa-ios
Liviqa citizen app — native iOS (Swift/SwiftUI, CoreML), Android-ready architecture. Owner: Data for Good.
Privacy-first: on-device processing, read-only HealthKit, local encrypted store, no cloud-by-default.
Built under QMS-lite (see /qms/). Baseline UI: locked v08 mockups + 09_Liviqa_iOS_Prototype. Extend, never redraw.
